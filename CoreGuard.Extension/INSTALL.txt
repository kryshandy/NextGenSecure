Installation de l'extension CoreGuard Browser Shield (Chrome, Edge, Brave, Chromium - Windows)
==============================================================================================

Methode recommandee (aucun droit administrateur) :

    ./scripts/install-browser-extension.ps1

Le script publie l'hote Native Messaging dans %LOCALAPPDATA%\CoreGuard\BrowserHost, ecrit son manifeste
(chemin absolu + extension autorisee : chrome-extension://dkmnbfljkgocbdiileppcmlcphbjbimi/) et le declare
pour chaque navigateur (HKCU\...\NativeMessagingHosts\com.coreguard.host).

Puis, une seule fois par navigateur : chrome://extensions > Mode developpeur > "Charger l'extension non
empaquetee" > dossier CoreGuard.Extension\extension. L'ID est fixe (cle publique dans manifest.json).

Desinstallation : ./scripts/install-browser-extension.ps1 -Uninstall

Securite : l'hote ne fait confiance a aucune donnee venant de l'extension ou de la page (taille bornee, JSON
valide, types de message en liste blanche). Les mots de passe ne sont fournis que par l'interface CoreGuard
(coffre deverrouille), uniquement si cet hote a ete lance par un navigateur signe, pour une page https.
